# Simulaci-n-del-compartimiento-del-inventario
l proyecto consiste en el desarrollo de una aplicación de consola en C++ diseñada para automatizar y optimizar el control de inventario de la tienda GadgetXpress. Nace como solución a los problemas generados por la gestión manual de sus productos, la cual provocaba errores, pérdida de tiempo y dificultades para tomar decisiones de reabastecimiento.
